# Sandeep Kumar Kumawat — Portfolio

Personal academic and research portfolio built with React, Vite, Tailwind CSS, Lucide React and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The profile photo and current CV are stored in `public/`. Update `src/data/portfolio_data.js` when changing portfolio details.
